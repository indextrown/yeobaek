# Swift 코드 스타일

## 적용 범위

- 새로 작성하거나 수정하는 Swift의 `func`, `init`, `init?`, `init!` 선언에 적용한다.
- 접근 수준과 관계없이 인스턴스 메서드, `static`·`class` 메서드, 전역 함수, 프로토콜 요구사항에도 적용한다.
- 호출부의 인자 배치와 클로저 문법은 이 규칙의 대상이 아니다. 별도 요청이 없으면 기존 스타일을 유지한다.
- 스킬을 사용한다는 이유만으로 작업 범위 밖의 코드를 일괄 수정하거나, 합성된 생성자를 명시적 생성자로 바꾸지 않는다.

## 매개변수가 있으면 항상 여러 줄로 선언한다

매개변수가 하나라도 있으면 선언이 짧더라도 다음 형식을 사용한다.

1. 여는 괄호 `(` 바로 뒤에서 줄을 바꾼다.
2. 매개변수마다 별도의 줄을 사용하고 한 단계 들여쓴다. 기존 들여쓰기 규칙이 없으면 공백 4칸을 사용한다.
3. 닫는 괄호 `)`는 별도 줄에 두고 선언 시작과 같은 깊이로 정렬한다.
4. `async`, `throws`, 반환 타입, 본문의 여는 중괄호는 닫는 괄호 뒤에 이어 쓴다.

`init(value: String)`처럼 매개변수를 여는 괄호와 같은 줄에 쓰거나, 한 줄에 여러 매개변수를 배치하지 않는다.

매개변수가 없는 `init()`과 `func refresh()`는 한 줄 괄호를 유지할 수 있다. 이 스킬만으로 문서화 주석이 필수가 되는 것도 아니다.

## 매개변수가 있는 선언은 항상 문서화한다

생성자를 포함해 매개변수가 있는 선언 바로 위에 `///` 문서화 주석을 작성한다. 일반 `//` 주석이나 타입에 달린 주석으로 대신하지 않는다.

- 첫 문장에 생성하거나 수행하는 동작의 의미를 설명한다.
- 매개변수가 하나이면 `- Parameter 이름:`으로 설명한다.
- 매개변수가 여러 개이면 `- Parameters:` 아래에 각 매개변수를 설명한다.
- 매개변수 이름은 외부 호출 레이블이 아니라 내부 이름을 사용한다. `for placeID:`와 `_ placeID:` 모두 `placeID`로 문서화한다.
- `Void`가 아닌 값을 반환하는 함수·메서드는 `- Returns:`로 반환값을 설명한다.
- `throws`·`rethrows` 선언은 `- Throws:`로 오류가 발생하거나 전달되는 조건을 설명한다. 근거 없이 구체적인 오류를 만들어 적지 않는다.
- 실패 가능한 생성자는 어떤 조건에서 `nil`이 되는지 요약에 설명한다.
- 매개변수의 단위, 기본값, `nil`의 의미처럼 사용에 필요한 조건을 설명한다. 타입 이름이나 대입문을 반복하는 무의미한 주석은 피한다.
- 문서화 주석은 한국어로 작성한다. 기존 파일에 영문 주석이 있어도 추가하거나 수정하는 문서화 주석은 한국어로 맞춘다. 코드 식별자, API 이름, URL, `- Parameter`·`- Parameters`·`- Returns`·`- Throws` 같은 문서화 표기는 원문을 유지한다.
- 프로토콜의 요구사항과 구현 메서드 모두 대상이다. 프로토콜에 주석이 있다는 이유로 구현의 주석을 생략하지 않는다.

## 예시: 여러 매개변수가 있는 생성자

```swift
/// 장소 코드와 해당 장소의 경계 정보를 연결합니다.
///
/// - Parameters:
///   - placeID: 경계가 속한 장소의 고유 코드입니다.
///   - polygons: 장소 영역을 구성하는 다각형 목록입니다.
public init(
    placeID: Place.ID,
    polygons: [GeoPolygon]
) {
    self.placeID = placeID
    self.polygons = polygons
}
```

## 예시: 매개변수가 하나인 생성자

```swift
/// 조회에 사용할 장소 코드를 보관합니다.
///
/// - Parameter placeID: 조회할 장소의 고유 코드입니다.
public init(
    placeID: Place.ID
) {
    self.placeID = placeID
}
```

## 예시: 매개변수가 하나인 비동기 메서드

```swift
public protocol CrowdRepository: Sendable {
    /// 지정한 장소의 혼잡도 정보를 조회합니다.
    ///
    /// - Parameter placeID: 조회할 장소의 고유 코드입니다.
    /// - Returns: 해당 장소의 혼잡도와 데이터 기준 시각을 담은 정보입니다.
    /// - Throws: 조회 실패 또는 요청 취소 시 발생하는 오류입니다.
    func fetchSnapshot(
        for placeID: Place.ID
    ) async throws -> CrowdSnapshot
}
```

## 변경 시 지킬 사항

- 스타일을 바꾸면서 접근 수준, 매개변수 레이블·순서·기본값, 반환 타입, 동시성 표기, 실행 동작을 변경하지 않는다.
- 선언을 변경할 때 문서화 주석도 함께 맞춘다. 모든 매개변수가 정확한 이름으로 설명되어야 한다.
- 코드 스타일 적용은 파일 수정 요청의 범위 안에서만 수행한다. 이 스킬 자체가 포맷터 실행, 빌드·테스트, 커밋·푸시를 승인하지는 않는다.
