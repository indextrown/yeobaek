# 서울 실시간 도시데이터 응답 항목

> 확인 기준: 2026-10-26 20시대, 샘플 키로 `광화문·덕수궁`(`POI009`)을 JSON으로 호출한 실제 응답  
> 공식 명세: [서울 실시간 도시데이터](https://data.seoul.go.kr/dataList/OA-21285/A/1/datasetView.do)

한 번 호출하면 아래 묶음이 하나의 응답으로 함께 온다. API 선택 기준과 `citydata_ppltn`과의 차이는 [실시간 혼잡도 API 조사 및 비교](실시간-혼잡도-API-조사.md)의 5장을 참고한다.

## 호출

```http
GET http://openapi.seoul.go.kr:8088/{SEOUL_API_KEY}/json/citydata/1/5/{AREA_NAME_OR_CODE}
```

- 한국어 API 공식 명세는 XML로 안내하지만 `json` 경로도 정상 응답했다.
- 한 번에 한 장소만 조회한다.
- 샘플 응답 크기는 장소 하나에 약 177KB다. 도로 구간 좌표(`XYLIST`) 등 큰 필드가 포함되므로 백엔드에서 필요한 항목만 추려 앱에 전달한다.
- 인구 수는 정확한 값이 아니라 최소·최대 범위로 온다.
- 값은 대부분 문자열이며, 빈 문자열이나 `None`이 올 수 있다.

| `BUS_STN_STTS` | 버스 정류소 | 목록 | 32 |
| `LIVE_BUS_PPLTN` | 버스 승하차 인원 | 객체 | - |

## 1. 실시간 인구 `LIVE_PPLTN_STTS`

| 필드 | 의미 | 샘플 값 |
|---|---|---|
| `AREA_CONGEST_LVL` | 혼잡도 단계 (여유·보통·약간 붐빔·붐빔) | `여유` |
| `AREA_CONGEST_MSG` | 혼잡도 안내 문구 | `사람이 몰려있을 가능성이 낮고…` |
| `AREA_PPLTN_MIN`, `AREA_PPLTN_MAX` | 추정 인구 범위 | `20000`, `22000` |
| `MALE_PPLTN_RATE`, `FEMALE_PPLTN_RATE` | 성별 비율(%) | `51.5`, `48.5` |
| `PPLTN_RATE_0` ~ `PPLTN_RATE_70` | 연령대별 비율(%, 10세 단위) | `PPLTN_RATE_30`: `23.2` |
| `RESNT_PPLTN_RATE`, `NON_RESNT_PPLTN_RATE` | 상주·비상주 인구 비율(%) | `22.1`, `77.9` |
| `REPLACE_YN` | 대체 데이터 여부 | `N` |
| `PPLTN_TIME` | 데이터 기준 시각 | `2026-10-26 20:10` |
| `FCST_YN` | 예측 데이터 제공 여부 | `Y` |
| `FCST_PPLTN` | 향후 12시간 예측 목록 | 12개 |

`FCST_PPLTN` 항목:

| 필드 | 의미 |
|---|---|
| `FCST_TIME` | 예측 시각 (1시간 단위) |
| `FCST_CONGEST_LVL` | 예측 혼잡도 단계 |
| `FCST_PPLTN_MIN`, `FCST_PPLTN_MAX` | 예측 인구 범위 |

## 2. 도로 소통 `ROAD_TRAFFIC_STTS`

장소 평균 `AVG_ROAD_DATA`:

| 필드 | 의미 | 샘플 값 |
|---|---|---|
| `ROAD_TRAFFIC_IDX` | 소통 상태 (원활·서행·정체) | `서행` |
| `ROAD_TRAFFIC_SPD` | 평균 속도(km/h) | `19` |
| `ROAD_MSG` | 안내 문구 | `해당 장소로 이동·진입시…` |
| `ROAD_TRAFFIC_TIME` | 기준 시각 | `2026-10-26 20:40` |

도로 구간 목록 `ROAD_TRAFFIC_STTS`:

| 필드 | 의미 |
|---|---|
| `LINK_ID`, `ROAD_NM` | 구간 ID, 도로명 |
| `START_ND_CD`, `START_ND_NM`, `START_ND_XY` | 시작 노드 코드·이름·좌표 |
| `END_ND_CD`, `END_ND_NM`, `END_ND_XY` | 끝 노드 코드·이름·좌표 |
| `DIST`, `SPD`, `IDX` | 거리(m), 속도, 소통 상태 |
| `XYLIST` | 구간 경로 좌표 (`경도_위도`를 `|`로 연결) |

## 3. 주차장 `PRK_STTS`

| 필드 | 의미 |
|---|---|
| `PRK_NM`, `PRK_CD`, `PRK_TYPE` | 주차장 이름, 코드, 유형 |
| `CPCTY` | 총 주차 면수 |
| `CUR_PRK_CNT`, `CUR_PRK_TIME`, `CUR_PRK_YN` | 현재 주차 대수, 기준 시각, 실시간 제공 여부 |
| `PAY_YN` | 유료 여부 |
| `RATES`, `TIME_RATES` | 기본 요금(원), 기본 시간(분) |
| `ADD_RATES`, `ADD_TIME_RATES` | 추가 요금(원), 추가 단위 시간(분) |

`SUB_DETAIL` 항목:

| 필드 | 의미 |

| `STAT_USETIME` | 이용 가능 시간 |
| `STAT_PARKPAY` | 주차료 여부 |

## 11. 실시간 상권 `LIVE_CMRCL_STTS`

카드 결제 데이터 기반이다.

| 필드 | 의미 | 샘플 값 |
|---|---|---|
| `AREA_CMRCL_LVL` | 상권 활성도 | `분주한` |
| `AREA_SH_PAYMENT_CNT` | 결제 건수 | `133` |
| `AREA_SH_PAYMENT_AMT_MIN`, `_MAX` | 결제 금액 범위(원) | `8500000`, `8600000` |
| `CMRCL_MALE_RATE`, `CMRCL_FEMALE_RATE` | 결제자 성별 비율(%) | `43.3`, `56.7` |
| `CMRCL_10_RATE` ~ `CMRCL_60_RATE` | 결제자 연령대 비율(%) | - |
| `CMRCL_PERSONAL_RATE`, `CMRCL_CORPORATION_RATE` | 개인·법인 결제 비율(%) | `41.5`, `58.5` |
| `CMRCL_TIME` | 기준 시각 | `20261026 2020` |
| `CMRCL_RSB` | 업종별 결제 목록 | 7개 |

`CMRCL_RSB` 항목은 `RSB_LRG_CTGR`(대분류, 예: 음식·음료), `RSB_MID_CTGR`(중분류, 예: 한식), `RSB_PAYMENT_LVL`(업종 활성도), `RSB_SH_PAYMENT_CNT`(결제 건수), `RSB_SH_PAYMENT_AMT_MIN`·`_MAX`(결제 금액 범위), `RSB_MCT_CNT`(가맹점 수), `RSB_MCT_TIME`(가맹점 수 기준 월)이다.

## 12. 재난문자·뉴스 `LIVE_DST_MESSAGE`, `LIVE_YNA_NEWS`

- `LIVE_DST_MESSAGE`: 긴급재난문자 목록이다. 샘플에서는 빈 목록이라 하위 필드를 확인하지 못했으며, 공식 명세에서 확인한다.
- `LIVE_YNA_NEWS`: 연합뉴스 목록이다. `YNA_STEP_NM`(분류), `YNA_TTL`(제목), `YNA_CN`(본문), `YNA_YMD`(일시), `YNA_WRTR_NM`(작성 매체)을 제공한다.

## 여백에서의 활용 후보

| 화면·기능 | 사용할 묶음 |
|---|---|
| 지도 혼잡도 | `LIVE_PPLTN_STTS`의 혼잡도 단계와 추정 인구 |
| 덜 붐비는 시간 추천 | `FCST_PPLTN` 12시간 예측 |
| 몰려드는 중인지 빠지는 중인지 | `LIVE_SUB_PPLTN`, `LIVE_BUS_PPLTN`의 최근 5·10·30분 승하차 |
| 식당가·상권 분위기 | `LIVE_CMRCL_STTS` |
| 혼잡 원인 설명 | `EVENT_STTS`, `WEATHER_STTS`, `ACDNT_CNTRL_STTS` |
| 이동 수단 안내 | `SUB_STTS`, `BUS_STN_STTS`, `SBIKE_STTS`, `PRK_STTS`, `ROAD_TRAFFIC_STTS` |

이 문서는 조사 기록이며 확정된 제품 동작이 아니다. 하위 데이터마다 기준 시각이 다르므로 화면에 표시할 때는 각 묶음의 시각 필드를 따로 사용한다.
