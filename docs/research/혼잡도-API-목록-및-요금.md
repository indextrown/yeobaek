# 혼잡도 API 목록 및 요금

> 조사 기준일: 2026-10-26  
> 조사 범위: 여백에서 사용할 수 있는 장소·지하철·버스 혼잡도 API와 공개된 요금 조건

API별 상세 분석과 키 발급 절차는 [실시간 혼잡도 API 조사 및 비교](실시간-혼잡도-API-조사.md)에서 다룬다. 이 문서는 후보 전체를 한눈에 비교하기 위한 목록이다. 요금과 호출 한도는 변경될 수 있으므로 계약이나 운영 전환 직전에 공식 페이지를 다시 확인한다.

## 요약

| 분류 | API | 제공처 | 실시간 | 비용 |
|---|---|---|---|---|
| 장소 | 서울 실시간 도시데이터 `citydata` | 서울 열린데이터광장 | O | 무료 |
| 장소 | 서울시 실시간 인구데이터 `citydata_ppltn` | 서울 열린데이터광장 | O | 무료 |

## 1. 장소 혼잡도

### 서울 실시간 도시데이터 / 실시간 인구데이터

| 항목 | 내용 |
|---|---|
| 데이터 | 혼잡도 4단계(여유·보통·약간 붐빔·붐빔), 추정 인구 범위, 향후 12시간 예측 |
| 범위 | 서울 주요 121개 장소, 한 번에 한 장소 조회 |
| 갱신 | 5분 단위 집계, 반영까지 약 15분 지연 |
| 요금 | 무료, 서울 열린데이터광장 일반 인증키 필요 |
| 호출 한도 | 일 1,000회라는 비공식 안내가 있으나 공식 페이지에서는 수치를 확인하지 못함. 활용사례(갤러리)에 등록해 승인받으면 호출 제한 없이 사용할 수 있다고 공식 안내함 |
| 샘플 키 | 광화문·덕수궁 한 곳만 조회 가능 |

`citydata`가 응답하는 항목 전체는 [서울 실시간 도시데이터 응답 항목](서울-실시간-도시데이터-응답-항목.md)에 정리했다.

- [서울 실시간 도시데이터](https://data.seoul.go.kr/dataList/OA-21285/A/1/datasetView.do)
- [서울시 실시간 인구데이터](https://data.seoul.go.kr/dataList/OA-21778/A/1/datasetView.do)
- [Open API 이용안내](https://data.seoul.go.kr/together/guide/useGuide.do)

### 한국관광공사 관광지 집중률 방문자 추이 예측

| 항목 | 내용 |
|---|---|
| 데이터 | 관광지별 조회일 기준 향후 30일 관광객 집중률 |
| 근거 | 이동통신 방문자 수 기반 예측치 |
| 범위 | 전국 관광지 |
| 요금 | 무료, 공공데이터포털 활용신청 필요 |
| 호출 한도 | 개발계정 일 1,000건 수준, 운영계정은 별도 신청 |

현재 혼잡도가 아니라 예측값이므로 "덜 붐비는 날짜 추천"에 적합하다.

- [공공데이터포털 API 정보](https://data.go.kr/catalog/15128555/openapi.json)

### SKT 장소 혼잡도 (지오비전 퍼즐)

| 항목 | 내용 |
|---|---|
| 데이터 | 쇼핑·여가 POI와 상권의 실시간·시간대별·통계성 혼잡도, 방문자 통계 |
| 범위 | SKT가 제공하는 POI·상권 목록 |
| 요금 | Free 월 10건 / Basic 33원/건, 일 한도 100건 / 해커톤 11원/건, 월 한도 3,000건 / 기업은 별도 문의 |
| 비고 | TMAP 상품에 포함된 퍼즐 장소 혼잡도는 Free 3건/일, Premium 8.8원/건으로 조건이 다르다 |

- [장소 혼잡도 요금](https://openapi.sk.com/products/calc?menuSeq=263&svcSeq=56)

### BestTime

| 항목 | 내용 |
|---|---|
| 데이터 | 장소별 시간대 혼잡 예측(0~100, 해당 장소의 주간 최대치를 100으로 둔 상대값), 일부 장소의 실시간 혼잡도 |
| 범위 | 전 세계. 한국 장소 커버리지는 직접 검증 필요 |
| 요금 | Basic Usage 월 최소 $29, 크레딧당 $0.04 / Pro Usage 월 $99 + 사용량 / Pro Venues 월 $96, 월 50개 장소 |
| 크레딧 | 새 예측 성공 2크레딧, 실패 1크레딧, 조회 1크레딧 |

Google Places API는 인기 시간대(Popular Times)를 응답 필드로 제공하지 않는다. BestTime은 그 대안으로 쓰이는 서드파티 서비스이며 Google 공식 데이터가 아니다. 실시간 값은 모든 장소에 있지 않고 영업시간에만 제공되므로 "실시간 정보 없음" 상태를 처리해야 한다.

- [BestTime 요금](https://besttime.app/subscription/pricing)
- [BestTime API 문서](https://documentation.besttime.app/)

## 2. 지하철 혼잡도

### SKT 지하철 혼잡도

| 항목 | 내용 |
|---|---|
| 데이터 | 지하철역 목록, 통계성 열차·칸 혼잡도, 칸별 하차 비율, 실시간 열차·칸 혼잡도, 출구별 통행자 통계 |
| 범위 | 수도권 1~9호선 및 신분당선 |
| 요금 | Free 월 10건 / Basic 33원/건, 일 한도 100건 / 해커톤 11원/건, 월 한도 3,000건 |
| 주의 | 공개 요금표의 값은 `지하철역 목록` 그룹에만 표시된다. 통계성 열차 혼잡도·출구 통계는 그룹명만 있고, **실시간 열차 혼잡도 그룹은 요금표에 없다.** 한도를 넘으면 자동으로 차단된다 |

- [지하철 혼잡도 상품](https://openapi.sk.com/products/detail?svcSeq=54)
- [지하철 혼잡도 요금](https://openapi.sk.com/products/calc?svcSeq=54&menuSeq=142)

### 서울교통공사 지하철 혼잡도

| 항목 | 내용 |
|---|---|
| 데이터 | 1~8호선, 요일 구분(평일·토·일), 역·상하선별 30분 단위 평균 혼잡도 |
| 기준 | 열차 1량 정원 대비 승차 인원. 승차 인원과 좌석 수가 같으면 34% |
| 형식 | API가 아닌 CSV 파일, 2024년부터 분기별 제공 |
| 요금 | 무료, 공공누리 제3유형(출처표시·변경금지) |

실시간 혼잡도는 공개 데이터셋이 아니라 또타 지하철 앱에서만 제공한다.

- [서울교통공사 지하철 혼잡도 정보](https://data.seoul.go.kr/dataList/OA-12928/F/1/datasetView.do)

### 서울교통공사 역별 승하차 인원 `getStnPsgr`

시간대별 승하차 흐름이며 현재 재실 인원이 아니다. 상세 내용은 [실시간 혼잡도 API 조사 및 비교](실시간-혼잡도-API-조사.md)의 4장을 참고한다. 요금은 무료다.

## 3. 버스 혼잡도

### 서울특별시 버스도착정보조회

| 항목 | 내용 |
|---|---|
| 데이터 | 버스 도착 정보와 차내 혼잡도 |
| 혼잡도 필드 | `brdrde_Num1`, `brdrde_Num2`. 재차 구분이 4일 때 혼잡도 코드(0 데이터 없음, 3 여유, 4 보통, 5 혼잡), 2일 때 재차 인원 또는 잔여 좌석 수 |
| 요금 | 무료, 개발계정 일 1,000건 수준 |

- [서울특별시_버스도착정보조회 서비스](https://www.data.go.kr/data/15000314/openapi.do)

### 경기도 버스도착정보

경기버스 앱이 공공데이터포털 API로 혼잡도를 표시하므로 혼잡도 필드가 있을 가능성이 높지만, 필드명은 확인하지 못했다. 사용 전 활용가이드에서 응답 필드를 확인한다. 요금은 무료다.

## 비용 관점 판단

| 단계 | 조합 | 월 비용 |
|---|---|---|
| MVP | 서울 실시간 도시데이터 + 서울교통공사 CSV + 서울 버스도착정보 | 0원 |
| 차별화 | 위 조합 + 관광공사 30일 예측 + SKT 실시간 칸 혼잡도 | SKT 요금 문의 필요 |
| 전국·해외 확장 | 위 조합 + SKT 장소 혼잡도 또는 BestTime | 호출량 기준 산정 필요 |

공공 API는 개발계정 한도가 낮다. 앱이 외부 API를 직접 호출하지 말고 여백 백엔드가 주기적으로 수집·캐시한 뒤 앱에 전달한다.
