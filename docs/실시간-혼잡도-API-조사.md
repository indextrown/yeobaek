# 여백 실시간 혼잡도 API 조사 및 비교

> 조사 기준일: 2026-08-27  
> 조사 범위: 대한민국에서 앱이 실제 호출할 수 있고, 사람 또는 장소의 현재 혼잡도를 제공하는 공개 API

## 결론

여백의 첫 버전은 **서울시 실시간 인구데이터 API**를 주 데이터 소스로 사용하는 것이 가장 현실적이다.

- 무료이며 상업적 이용과 변경이 가능한 공공누리 제1유형 데이터다.
- `여유`, `보통`, `약간 붐빔`, `붐빔`의 4단계 혼잡도와 추정 인구 범위, 향후 12시간 예측값을 제공한다.
- 서울의 주요 121개 장소만 지원하고 한 번에 한 장소만 조회할 수 있다는 한계가 있다.
- API 응답에 지도 영역 좌표가 포함되지 않으므로, 데이터셋에서 제공하는 121개 장소 영역 파일을 받아 지도 폴리곤으로 변환해야 한다.

서울 밖으로 서비스 범위를 확장할 때는 **SK텔레콤 장소 혼잡도 API**를 검토한다. 지원 POI·상권의 혼잡도를 제공하지만, 무료 호출량이 매우 적고 실제 서비스 트래픽에는 비용이 발생한다.

## 핵심 비교

| 항목 | 서울시 실시간 인구데이터 | SKT 장소 혼잡도 | SKT 지하철 혼잡도 |
|---|---|---|---|
| 주 용도 | 서울 주요 지역의 보행·장소 혼잡도 | 쇼핑·여가 장소와 상권 혼잡도 | 역사·열차·객차 혼잡도 |
| 공간 범위 | 서울 주요 121개 장소 | SKT가 제공하는 POI·상권 | 수도권 1~9호선 및 신분당선 |
| 실시간 값 | 혼잡도 4단계, 추정 인구 범위 | 혼잡도 수치, 레벨 1~4 | 열차·객차별 혼잡도 |
| 예측·통계 | 향후 12시간 예측 | 시간대별·통계성 혼잡도, 방문자 통계 | 통계성 열차 혼잡도, 출구 통계 |

| 비용 | 무료 | 무료 체험량이 작고 운영은 유료 | 무료 체험량이 작고 운영은 유료 |
| 여백 MVP 적합도 | **높음** | 중간 | 대중교통 기능을 추가할 때 높음 |

## 1. 서울시 실시간 인구데이터 API

### 제공 내용

[서울시 실시간 인구데이터 공식 페이지](https://data.seoul.go.kr/dataList/OA-21778/A/1/datasetView.do)는 서울 주요 121개 장소의 실시간 인구 현황을 제공한다. 원천 데이터는 통신 신호를 바탕으로 전체 인구를 추정한 값이다.

주요 응답 필드는 다음과 같다.

| 필드 | 의미 | 여백에서의 사용 |
|---|---|---|
| `AREA_NM` | 장소명 | 지도 라벨 |
| `AREA_CD` | 장소 코드 | 내부 장소 ID |
| `AREA_CONGEST_LVL` | 혼잡도 4단계 | 폴리곤 색상과 상태 문구 |
| `AREA_CONGEST_MSG` | 혼잡도 설명 | 상세 화면 안내 |
| `AREA_PPLTN_MIN` | 추정 인구 최소값 | 예상 인구 범위 |
| `AREA_PPLTN_MAX` | 추정 인구 최대값 | 예상 인구 범위 |
| `PPLTN_TIME` | 데이터 기준 시각 | 최신성 표시 |
| `FCST_PPLTN` | 예측 인구 배열 | 시간대별 혼잡도 차트 |

혼잡도는 최근 28일의 동일 장소 인구, 장소 면적 대비 밀집도, 장소 특성 등을 반영해 `여유`, `보통`, `약간 붐빔`, `붐빔`으로 산출된다. 자세한 산출 방식과 데이터 지연은 [서울 실시간 도시데이터 매뉴얼](https://data.seoul.go.kr/SeoulRtd/downloads/%EC%8B%A4%EC%8B%9C%EA%B0%84_%EB%8F%84%EC%8B%9C%EB%8D%B0%EC%9D%B4%ED%84%B0_%EB%A7%A4%EB%89%B4%EC%96%BC.pdf)에서 확인할 수 있다.

### 호출 예시

```http
GET http://openapi.seoul.go.kr:8088/{SEOUL_API_KEY}/json/citydata_ppltn/1/5/{AREA_NAME_OR_CODE}
```

예를 들어 장소 코드나 URL 인코딩한 `광화문·덕수궁`을 마지막 경로에 넣는다. 샘플 키는 광화문·덕수궁만 조회할 수 있으며, 전체 장소는 인증키가 필요하다.

### 갱신과 지연

- 실시간 인구 원천값은 5분 단위로 집계된다.
- 통신 데이터를 전체 인구로 확장·보정해 제공하기까지 약 15분이 걸린다.
- 앱에서는 `PPLTN_TIME`을 기준으로 최신성을 판단해야 하며, 단순히 요청 시각을 데이터 시각으로 표시하면 안 된다.
- 네트워크 호출 주기를 데이터 생성 주기보다 짧게 잡아도 새 데이터가 생기지 않으므로 5분 캐시를 기본값으로 권장한다.

### 장점

- 무료로 시작할 수 있다.
- 혼잡도와 추정 인구가 앱 기능에 바로 사용할 수 있는 형태로 제공된다.
- 향후 12시간 예측값이 있어 “지금보다 덜 붐비는 시간”을 추천할 수 있다.
- 데이터셋 페이지의 이용허락범위는 공공누리 제1유형으로, 출처 표시 조건에서 상업적 이용과 변경이 가능하다.

### 제약

- 서울 전역의 임의 좌표가 아니라 미리 정한 121개 장소만 제공한다.
- API 한 번에 한 장소만 호출할 수 있다. 지도 전체를 갱신하려면 백엔드에서 장소별로 호출하고 캐시해야 한다.
- API 응답 자체에는 장소 폴리곤이나 대표 좌표가 없다. 공식 데이터셋에 첨부된 `서울시 주요 121장소 영역` 파일을 별도로 내려받아 GeoJSON 등으로 변환해야 한다.
- 장기 과거 데이터는 이 API가 제공하지 않는다. 추세 분석이 필요하면 여백 서버가 이용조건을 확인한 뒤 자체 집계 데이터를 저장해야 한다.
- 공개 서비스 전 서울 열린데이터광장의 인증키 운영 조건과 호출 정책을 다시 확인해야 한다.

## 2. SK텔레콤 장소 혼잡도 API

### 제공 내용

[SK open API 장소 혼잡도](https://openapi.sk.com/products/detail?svcSeq=56)는 쇼핑·여가 장소와 상권의 혼잡도 및 방문자 통계를 제공한다.

- 지원 POI와 상권 목록
- 실시간·시간대별·통계성 장소 혼잡도
- 실시간·시간대별·통계성 상권 혼잡도
- 일자별 방문자 수, 유입력, 연령 분포, 방문자 유형
- 혼잡도 수치와 1~4 단계 레벨

실시간 장소 혼잡도는 요청 시점에서 가장 최근에 집계된 값이며, 조회 시점 기준 1시간 동안의 **1㎡당 추정 방문자 수**를 기반으로 한다.

### 주요 엔드포인트

```http
GET https://apis.openapi.sk.com/puzzle/place/meta/pois
GET https://apis.openapi.sk.com/puzzle/place/meta/areas
GET https://apis.openapi.sk.com/puzzle/place/congestion/rltm/pois/{poiId}
GET https://apis.openapi.sk.com/puzzle/place/congestion/rltm/areas/{areaId}

appKey: {SK_APP_KEY}
Content-Type: application/json
```

먼저 메타 API로 지원하는 `poiId` 또는 `areaId`를 확보한 뒤 해당 ID의 혼잡도를 조회하는 방식이다. 임의 위·경도를 보내 전국 모든 지점의 혼잡도를 받는 API는 아니다.

### 요금

[장소 혼잡도 요금 페이지](https://openapi.sk.com/products/calc?menuSeq=263&svcSeq=56)에 표시된 기준은 다음과 같다. 요금은 변경될 수 있으므로 계약 직전에 다시 확인해야 한다.

| 요금제 | 표시된 호출 조건 |
|---|---|
| Free | 월 10건 |
| Basic | 33원/건, 일 한도 100건 |
| 해커톤 | 11원/건, 월 한도 3,000건, 담당자 확인 필요 |
| 기업 | 사용량에 따라 별도 문의 |

TMAP 상품에 포함된 `puzzle 장소 혼잡도`는 [TMAP 요금 페이지](https://openapi.sk.com/products/calc?menuSeq=5&svcSeq=4)에서 별도 조건으로 제공된다. 현재 페이지에는 Free 3건/일, Premium 8.8원/건으로 표시되어 있다. 같은 데이터라도 가입한 상품에 따라 한도와 요금이 달라질 수 있으므로 프로젝트 생성 시 선택한 상품 기준으로 확인한다.

### 장점

- 서울시의 고정된 핫스팟 체계와 달리 SKT가 지원하는 POI와 상권을 다룰 수 있다.
- 장소와 상권 단위의 실시간 혼잡도를 같은 체계로 받을 수 있다.
- 방문자 통계까지 있어 이후 개인화나 장소 추천으로 확장하기 좋다.

### 제약

- 무료 한도는 실제 지도 서비스를 운영하기에 부족하다.
- 지원 대상은 SKT가 제공하는 POI·상권 목록으로 제한된다.
- 장소 목록 조회도 호출량에 포함될 수 있으므로 목록을 자주 다시 받지 말고 서버에 캐시해야 한다.
- 상용 출시 전 데이터 표시, 저장, 재가공, 제3자 제공에 관한 최신 상품 약관을 확인해야 한다.

## 3. SK텔레콤 지하철 혼잡도 API

[SK open API 지하철 혼잡도](https://openapi.sk.com/products/detail?svcSeq=54)는 수도권 1~9호선 및 신분당선의 역사와 열차에 대한 혼잡도를 제공한다.

- 실시간 열차·객차 혼잡도
- 진입 역 기준 실시간 혼잡도
- 통계성 열차·객차 혼잡도
- 지하철역 출구 통행자 통계

장소 혼잡도를 지도에 표시하는 여백의 핵심 API를 대체하지는 않는다. 다만 역 주변 혼잡도 상세 화면이나 “덜 붐비는 객차” 기능을 추가할 때 유용하다. [공식 요금 페이지](https://openapi.sk.com/products/calc?menuSeq=142&svcSeq=54)에 따르면 무료 체험량은 월 10건 수준이고, Basic은 33원/건으로 표시되어 있어 운영 비용을 별도로 계산해야 한다.

## 공개 API로 사용하기 어려운 후보

### Google Maps 인기 시간대

Google Maps 소비자 화면에는 장소별 인기 시간대가 보일 수 있지만, [Google Places API Place Details 공식 필드](https://developers.google.com/maps/documentation/places/web-service/place-details)에는 실시간 혼잡도나 Popular Times가 공개 응답 필드로 문서화되어 있지 않다. 비공식 스크래핑에 의존하면 안정성과 이용약관 문제가 생기므로 여백의 데이터 소스로 사용하지 않는다.

### 네이버 지도·카카오 로컬 API

[네이버 지도 API](https://www.ncloud.com/product/applicationService/maps)와 [카카오 로컬 API](https://developers.kakao.com/docs/latest/ko/local/dev-guide)는 지도 표시, 주소 변환, 장소 검색 등에 사용할 수 있지만 공식 공개 문서에서 장소의 실시간 인파 혼잡도를 제공하는 필드는 확인되지 않았다. 두 서비스는 **배경 지도 또는 장소 검색** 후보이지 혼잡도 원천 데이터 후보는 아니다.

### 서울 생활인구·일반 유동인구 통계

생활인구와 통신사 유동인구 통계는 구역별 인구 분석에는 유용하지만, 현재 시점의 혼잡도를 앱에 즉시 표시하는 용도와는 갱신 시점·제공 단위가 다르다. 실시간 API 장애 시 대체값으로 바로 사용하지 말고 `통계 기반 예상`이라고 명확히 구분해야 한다.

### 도로 교통 혼잡도

TMAP, 국가교통정보센터, 한국도로공사 등의 실시간 교통정보는 차량 속도와 도로 정체를 나타낸다. 보행 인파나 장소의 붐빔 정도와 의미가 다르므로 여백의 핵심 혼잡도와 섞지 않는다.

## 권장 MVP 데이터 구조

외부 API의 필드명을 앱 화면에서 직접 사용하지 말고, 백엔드에서 다음과 같이 정규화한다.

```json
{
  "placeId": "POI001",
  "name": "광화문·덕수궁",
  "level": "RELAXED",
  "levelLabel": "여유",
  "estimatedPopulation": {
    "min": 12000,
    "max": 14000
  },
  "observedAt": "2026-08-27T14:30:00+09:00",
  "fetchedAt": "2026-08-27T14:46:00+09:00",
  "source": "SEOUL_REALTIME_POPULATION",
  "isForecast": false
}
```

권장 내부 레벨은 `RELAXED`, `NORMAL`, `BUSY`, `CROWDED`, `UNKNOWN`이다. 데이터가 오래되거나 API가 실패했을 때 마지막 값을 현재 값처럼 보여주지 말고 `UNKNOWN` 또는 “업데이트 지연” 상태를 표시한다.

## 권장 구현 순서

1. 서울 열린데이터광장에서 인증키를 발급받는다.
2. 121개 장소 목록과 영역 파일을 내려받아 장소 코드와 지도 폴리곤을 연결한다.
3. 서버에서 장소별 API를 호출하고 최소 5분간 캐시한다.
4. API 키는 앱에 넣지 않고 서버 환경 변수나 비밀 저장소에서 관리한다.
5. `PPLTN_TIME`과 서버 수집 시각을 함께 저장해 데이터 지연을 감지한다.
6. 지도에는 폴리곤 또는 대표점으로 혼잡도를 표시하고 서울시 출처를 노출한다.
7. MVP 사용성을 확인한 뒤 전국 확장이 필요할 때 SKT 지원 POI 목록과 월 예상 호출 비용을 산정한다.

## 최종 선택

| 단계 | 선택 | 이유 |
|---|---|---|
| MVP | 서울시 실시간 인구데이터 | 무료, 4단계 혼잡도와 예측 제공, 구현 가능성이 가장 높음 |
