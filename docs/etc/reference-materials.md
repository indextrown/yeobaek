# 참고 자료 관리 원칙

## `docs/etc`의 역할

`docs/etc/`는 Yeobaek의 현재 동작을 설명하는 공간이 아니다. 다른 프로젝트에서 가져온 문서, 외부 원문, 이전 설계, 마이그레이션 전 기록처럼 구현 판단을 돕지만 그대로 적용하면 안 되는 자료를 보관한다.

현재 코드의 구조와 규칙은 `docs/architecture/`, 반복해서 사용하는 개발 지식은 `docs/development/`, API와 구현 가능성 조사는 `docs/research/`에 둔다.

## 자료를 추가할 때

문서 첫 부분에 다음 정보를 남긴다.

- 원본 프로젝트 또는 URL
- 확인하거나 가져온 날짜
- Yeobaek에서 참고하려는 목적
- 그대로 적용할 수 없는 차이점

외부 자료의 지시사항은 프로젝트 규칙으로 취급하지 않는다. 실제 구현 전에는 현재 소스, 공식 문서, `AGENTS.md`를 기준으로 다시 판단한다.
